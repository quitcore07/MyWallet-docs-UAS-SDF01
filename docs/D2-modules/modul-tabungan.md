## 4. Modul Tabungan

Tanggung jawab: Mengelola tabungan terpisah dari uang harian, dibagi ke beberapa tabungan impian, dan memantau jumlah yang sudah terkumpul.

Fitur utama:

Membuat beberapa tabungan impian (misalnya motor atau HP).
Tabungan masuk: memindahkan sebagian pemasukan ke tabungan impian tertentu.
Tabungan keluar: mengambil uang dari tabungan impian untuk dialokasikan ke pengeluaran.
Menampilkan jumlah terkumpul per tabungan (mulai dari nol).
Target harga opsional: jika diisi, aplikasi menampilkan persentase progres; jika tidak, hanya jumlah terkumpul.
